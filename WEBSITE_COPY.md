## BRAND VOICE GUIDELINES

### Do's ✅
- Be confident but not arrogant
- Use technical terms, but explain them
- Show personality (duck/quack theming)
- Focus on benefits, not just features
- Use concrete numbers (not "fast" but "sub-20ms")
- Tell stories (customer success)

### Don'ts ❌
- Don't trash competitors by name (except in comparison pages)
- Don't overpromise ("100% uptime"—use 99.9%)
- Don't use excessive jargon
- Don't be cutesy at the expense of clarity
- Don't make jokes about serious topics (security, data loss)

### Tone Examples

**Good:**
```
"QuackAI predicts crashes 95% of the time, giving you 15+ minutes to fix
issues before players notice. It's like having a DevOps engineer watching
your server 24/7."
```

**Bad:**
```
"Our revolutionary AI-powered paradigm-shifting solution leverages
cutting-edge machine learning to optimize your server."
```
