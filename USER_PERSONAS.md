# QuackHost User Personas & Customer Journey Maps

**Last Updated:** 2025-11-16

---

## Executive Summary

QuackHost serves four primary personas, each with distinct needs, behaviors, and monetization potential. Understanding these personas allows us to tailor product features, marketing messages, and customer success strategies for maximum retention and lifetime value.

---

## Persona 1: "First-Timer Finn"
### The Casual Hobbyist

**Demographics:**
- Age: 15
- Location: Suburban USA
- Occupation: High school student
- Income: $0 (allowance from parents)
- Gaming Hours: 15-20 hours/week

**Psychographics:**
- Loves Minecraft, plays with 5-8 school friends
- Tech-savvy but no server experience
- Budget-conscious (no income)
- Influenced by YouTube tutorials
- Active on Discord

**Goals:**
- Play Minecraft with friends online
- Have a server that "just works"
- Customize with mods/plugins
- Impress friends with cool server

**Pain Points:**
- Confused by technical setup
- Can't afford expensive hosting
- Worried about downtime
- Doesn't know which plugins to use
- Parents won't give credit card

**Behaviors:**
- Searches "free minecraft server hosting"
- Watches YouTube tutorials for everything
- Asks friends for recommendations
- Tries multiple hosts before settling
- Active in Minecraft subreddits

**QuackHost Appeal:**
- **Free tier:** No credit card needed
- **Simple setup:** Running in 2 minutes
- **One-click mods:** No technical knowledge required
- **Modern UI:** Feels like gaming, not enterprise software
- **Community:** Discord with other young server owners

**Revenue Potential:**
- **Current:** $0 (free tier)
- **Future:** $5-15/mo (when server grows or gets first job)
- **Lifetime Value:** $300-500 over 3 years

**Key Features for Finn:**
- Free tier (5 players)
- One-click Minecraft server
- Pre-made templates (survival, creative, minigames)
- YouTube tutorials library
- Discord integration
- Friend referral rewards

**Marketing Messages:**
- "Free Minecraft server in 2 minutes"
- "No credit card required"
- "10,000+ students trust QuackHost"
- "Watch your server come alive"

## Customer Journey Maps

### 7.1 Journey Map: First-Timer Finn

#### Stage 1: Awareness (Day -7)
**Touchpoint:** YouTube tutorial
- **Thought:** "I want to play Minecraft with friends"
- **Feeling:** Excited
- **Action:** Searches "how to make minecraft server"
- **Pain Point:** Sees complex technical tutorials
- **QuackHost Opportunity:** Sponsored video "Easiest way to make a server"

#### Stage 2: Consideration (Day -3)
**Touchpoint:** Google search
- **Thought:** "Which free host is best?"
- **Feeling:** Confused by options
- **Action:** Compares QuackHost vs competitors
- **Pain Point:** Other free tiers require credit card
- **QuackHost Win:** No credit card required

#### Stage 3: Decision (Day 0)
**Touchpoint:** Landing page
- **Thought:** "This looks easy"
- **Feeling:** Cautiously optimistic
- **Action:** Clicks "Start Free Server"
- **Pain Point:** Worried it's too good to be true
- **QuackHost Win:** Social proof "10K students use QuackHost"

#### Stage 4: Onboarding (Day 0, Hour 1)
**Touchpoint:** Signup flow
- **Thought:** "Wow, this is actually simple"
- **Feeling:** Delighted
- **Action:** Selects Minecraft, creates server
- **Pain Point:** Not sure what to do next
- **QuackHost Win:** In-app tutorial, server ready in 2 min

#### Stage 5: First Value (Day 0, Hour 2)
**Touchpoint:** Server dashboard
- **Thought:** "I did it! Friends can join!"
- **Feeling:** Proud, accomplished
- **Action:** Shares IP with friends on Discord
- **Pain Point:** One friend can't connect (firewall)
- **QuackHost Win:** Help docs + live chat resolves immediately

#### Stage 6: Engagement (Day 3)
**Touchpoint:** Email + in-app
- **Thought:** "The server is full, friends can't join"
- **Feeling:** Frustrated
- **Action:** Considers upgrading
- **Pain Point:** Doesn't have money
- **QuackHost Win:** "Refer 2 friends, get $10 credit"

#### Stage 7: Advocacy (Day 7)
**Touchpoint:** Referral program
- **Thought:** "I'll tell my friends about this"
- **Feeling:** Grateful
- **Action:** Shares referral link in school Discord
- **Pain Point:** None
- **QuackHost Win:** 3 friends sign up, Finn gets $30 credit

#### Stage 8: Conversion (Day 14)
**Touchpoint:** Upgrade prompt
- **Thought:** "Server is growing, need more slots"
- **Feeling:** Excited about growth
- **Action:** Upgrades to Duckling ($5/mo) using referral credits
- **Pain Point:** Needs to convince parents
- **QuackHost Win:** "Only $5/month, same as Netflix for one person"

#### Stage 9: Retention (Month 3)
**Touchpoint:** Community events
- **Thought:** "QuackHost is more than just hosting"
- **Feeling:** Part of a community
- **Action:** Joins Discord, participates in build contest
- **Pain Point:** Skill gap (others are better builders)
- **QuackHost Win:** Beginner category in contests

#### Stage 10: Expansion (Month 6)
**Touchpoint:** Marketplace launch
- **Thought:** "I can sell my custom plugin!"
- **Feeling:** Entrepreneurial
- **Action:** Uploads plugin to marketplace
- **Pain Point:** Code quality not perfect
- **QuackHost Win:** Code review + mentorship program

**Lifecycle:** Free User → Paid User → Creator → Advocate
