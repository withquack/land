## 2. Unit Economics Analysis

### Traditional Fixed Pricing Model

**Per Server Economics:**
- Revenue: $20/month
- Infrastructure Cost: $8/month (AWS/bare metal)
- Gross Profit: $12/month (60% margin)
- Support Cost: $4/month (amortized)
- **Net Contribution Margin:** $8/month (40%)

**Customer Lifetime Economics:**
- Average Retention: 24 months
- Churn Rate: 4.2% monthly
- LTV: $20 × 24 × 0.4 = $192 (contribution margin based)
- CAC: $100 (paid ads, affiliate commissions)
- **LTV:CAC = 1.9:1** (marginal, needs improvement)

### New Usage-Based Pricing Model

**Per Player-Hour Economics:**
- Price: $0.01/player-hour
- Infrastructure: $0.003/player-hour (70% reduction via containerization)
- Gross Profit: $0.007/player-hour (70% margin!)
- Support: $0.001/player-hour (AI-powered, minimal)
- **Net Contribution Margin:** $0.006/player-hour (60%)

**Example Server:**
- 20 active players × 5 hours/day × 30 days = 3,000 player-hours/month
- Revenue: $30/month (+50% vs fixed)
- Net Margin: $18/month (+125% vs fixed)
- **Better economics for both customer and QuackHost**

**Hybrid Model (Recommended):**
- Base: $5/month (covers hibernation, storage)
- Usage: $0.01/player-hour
- Typical customer pays $15-25/month but gets better value
- QuackHost margins improve 20-30%

## 4. Growth Drivers & CAC Efficiency

### Traditional Growth (Paid Acquisition)
- CAC: $100 (Google Ads, affiliate marketing)
- Conversion Rate: 2% (landing page → signup)
- Monthly Growth: 5% (capital intensive)

### Viral Growth Mechanisms

**4.1 Referral Program**
- Incentive: $10 credit + 5% lifetime revenue share
- Cost per Acquisition: $30 (vs $100 paid)
- Viral Coefficient: 0.6 (each user refers 0.6 users)
- **70% cheaper than paid, compounds over time**

**4.2 Server Templates**
- Each popular server spawns 10 clones (avg)
- Template conversion rate: 15%
- CAC: $5 (just template hosting cost)
- **95% cheaper acquisition**

**4.3 Creator Partnerships**
- 10,000 creators × 100 followers each = 1M potential customers
- Conversion: 5% = 50,000 customers
- CAC: $20 (creator commissions)
- **80% cheaper, higher quality leads**

**4.4 Freemium Conversion**
- Free → Paid conversion: 10%
- CAC for paid: $0 (already using product)
- Upgrade LTV: $500+
- **Infinite LTV:CAC ratio**

**Blended CAC (Year 3+):**
- 20% Paid ($100) = $20 blended
- 30% Referral ($30) = $9 blended
- 20% Templates ($5) = $1 blended
- 20% Creators ($20) = $4 blended
- 10% Freemium ($0) = $0 blended
- **Total Blended CAC: $34** (vs $100 current)
- **LTV remains $480+**
- **New LTV:CAC = 14:1** (world-class)
