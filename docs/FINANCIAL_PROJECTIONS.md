## Unit Economics

### Cost Per Server (Year 3)

**Infrastructure cost per server:** $415K / 50K = $8.30/month

**Total cost per server:** $3.57M / 3 months / 50K = $23.80/month

**Revenue per server:** $45/month (average)

**Gross margin per server:** $45 - $8.30 = $36.70 (82% margin)

**Contribution margin:** $45 - $23.80 = $21.20 (47% margin)

### Customer Acquisition Cost (CAC)

**Year 1:**
- Marketing spend: $425K
- New customers: 2,000
- CAC: $212.50

**Year 3:**
- Marketing spend: $800K/year
- New customers: 40,000/year
- CAC: $20

**CAC Payback Period:** 1.2 months (improving with scale)

### Lifetime Value (LTV)

**Average server lifetime:** 24 months (assumes 5% monthly churn)

**LTV:** $45/month x 24 months = $1,080

**LTV:CAC Ratio:**
- Year 1: 1080 / 212.50 = 5.1x
- Year 3: 1080 / 20 = 54x
