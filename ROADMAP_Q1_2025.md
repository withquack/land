## 🚀 Key Features Shipping in Q1

### 1. Freemium Tier
**Value Prop:** "Start free, upgrade when you grow"

**Features:**
- 10 player slots
- 2GB RAM
- 10GB SSD storage
- Standard support (community forum)
- QuackHost branding in MOTD
- 99% uptime SLA

**Limitations:**
- No custom domain
- No automated backups
- No priority support
- Server hibernates after 7 days inactive

**Upgrade Path:**
- Remove branding: $5/month
- 20 players: $10/month
- 40 players: $20/month
- Unlimited: $50/month

### 2. Referral System
**Mechanics:**
- Unique referral link for every user
- $10 credit for referrer when referee spends $20+
- $10 credit for referee on signup
- Bonus: 10 referrals = free month ($20 value)
- Lifetime tracking (recurring commission potential)

**Viral Loop:**
1. User signs up (free or paid)
2. Gets referral link in welcome email
3. Shares with friends (incentivized)
4. Friends sign up and upgrade
5. User gets credits, shares more
6. Exponential growth

### 3. Multi-Game Support
**Launch Games:**
- Minecraft Java (existing)
- Minecraft Bedrock (cross-platform)
- Terraria (2D sandbox)
- Valheim (survival RPG)

**Features:**
- One-click game switching
- Game-specific templates
- Automatic version updates
- Mod/plugin support per game
- Cross-game server management

### 4. Mobile App
**Platform:** iOS + Android
**Core Features:**
- Server management (start/stop/restart)
- Player management (kick/ban)
- Console access
- Performance monitoring
- Push notifications
- File browsing

**Future:** In-app purchases, server creation

### 5. QuackGPT Support
**AI Chatbot:**
- Natural language troubleshooting
- "My server is lagging" → diagnostics + solutions
- Configuration help
- Plugin/mod recommendations
- 24/7 availability
- Escalate to human for complex issues

### 6. Template Library Expansion
**Goal: 200 templates by end of Q1**

**Categories:**
- Vanilla (standard, hardcore, skyblock)
- Modpacks (FTB, Tekkit, ATM, RLCraft)
- Minigames (Bedwars, Skyblock, Prison)
- Creative (plots, WorldEdit)
- RPG (quests, classes, custom items)
- PvP (factions, KitPVP)

**Per Game:** 30-50 templates each
